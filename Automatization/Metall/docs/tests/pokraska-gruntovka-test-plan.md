## Edge cases для AQA

- [ ] Маляр открывает бота, СВАРКА не выполнена → задача ПОКРАСКА с иконкой ☐, при нажатии alert "☐ Ожидает готовности предыдущего этапа"
- [ ] Маляр открывает бота, СВАРКА выполнена → задача ПОКРАСКА доступна, открывается карточка
- [ ] Маляр ставит ВЫПОЛНЕНО на ПОКРАСКА → задача ГРУНТОВКА разблокируется (если БЛОК), грунтовщик получает уведомление
- [ ] Грунтовщик открывает бота, ПОКРАСКА не выполнена → задача ГРУНТОВКА с ☐
- [ ] Грунтовщик открывает бота, ПОКРАСКА выполнена → задача доступна
- [ ] Задача ПОКРАСКА без строки в ЗАВИСИМОСТИ → `deps_ready=True`, задача сразу доступна
- [ ] Мастер "Планы на сегодня" → ПОКРАСКА и ГРУНТОВКА отображаются с иконками 🎨 и 🪣 в правильном порядке
- [ ] Мастер "По цехам" в карточке проекта → прогресс-бары для ПОКРАСКА и ГРУНТОВКА присутствуют
- [ ] Мастер "Выработка" → маляр/грунтовщик отображается в разбивке по ПОКРАСКА / ГРУНТОВКА
- [ ] Рабочий ПОКРАСКА/ГРУНТОВКА не в СОТРУДНИКИ → бот выдаёт "Вы не найдены в системе"
- [ ] Мастер ставит БЛОК на задачу ПОКРАСКА → мастер получает уведомление с кнопкой "Снять блок"
- [ ] Мастер снимает БЛОК → статус→ПЛАН, рабочий получает "Блокировка снята"
