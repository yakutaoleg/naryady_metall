# PRD: Специализации «Покраска» и «Грунтовка»

**Дата:** 2026-07-21  
**Статус:** Approved  
**Автор:** Product Manager Agent  
**Проект:** Metall Bot (Telegram бот для цеха металлоконструкций)

---

## 1. Problem Statement

Цех выполняет покрасочные и грунтовочные работы, но они не учитываются в системе нарядов. Рабочие этих специализаций не могут получать задания через бот, а мастер не видит прогресс по этим этапам. Это создаёт пробел в общем контроле производственного процесса.

Покраска и Грунтовка — финальные этапы обработки элементов после сборки и сварки. Без их интеграции невозможно отслеживать полный производственный цикл: ПЛАЗМА/ПИЛА → СБОРКА → СВАРКА → ПОКРАСКА → ГРУНТОВКА.

---

## 2. Цели

**Бизнес-цель:** Замкнуть производственный цикл в системе — от резки металла до финишной обработки. Все этапы должны быть видны мастеру и учитываться в выработке.

**Метрика успеха:**
- Рабочие Покраски и Грунтовки получают задания через бот так же, как ПЛАЗМА/ПИЛА/СБОРКА/СВАРКА
- Мастер видит прогресс по этим специализациям наравне с остальными
- Нет ситуаций, когда задача на Покраску выдана раньше, чем элемент прошёл Сварку
- Нет ситуаций, когда задача на Грунтовку выдана раньше, чем элемент прошёл Покраску

---

## 3. Целевые пользователи

| Роль | Контекст |
|------|----------|
| Рабочий-маляр | Получает список элементов для покраски через бот, отмечает выполнение |
| Рабочий-грунтовщик | Получает список элементов для грунтовки через бот, отмечает выполнение |
| Мастер | Создаёт наряды вручную в Google Sheets, контролирует прогресс, снимает блоки, видит выработку |

---

## 4. Решения по ключевым вопросам

Ниже зафиксированы подтверждённые ответы заказчика.

| Вопрос | Решение |
|--------|---------|
| Как заполняются вкладки? | Вручную мастером на уровне создания наряда — так же как ПЛАЗМА/ПИЛА/СБОРКА/СВАРКА |
| Порядок этапов | СБОРКА → СВАРКА → ПОКРАСКА → ГРУНТОВКА. Покраска зависит от Сварки, Грунтовка зависит от Покраски |
| Нужен ли бот? | Да, полноценный. Маляры и грунтовщики работают через бот как все остальные рабочие |
| Структура вкладки | Те же колонки, что в вкладке СВАРКА |
| Вкладка СОТРУДНИКИ | Добавить разделы для специализаций "Покраска" и "Грунтовка" |

## 5. User Stories

- [ ] Как **рабочий-маляр**, я хочу видеть в боте список элементов для покраски, чтобы знать что и когда красить
- [ ] Как **рабочий-грунтовщик**, я хочу видеть в боте список элементов для грунтовки, чтобы выполнять задачи в нужном порядке
- [ ] Как **рабочий**, я хочу отмечать элемент как ВЫПОЛНЕНО после покраски/грунтовки, чтобы мастер видел прогресс
- [ ] Как **рабочий-маляр**, я не хочу видеть задачу на элемент, пока он не прошёл Сварку (статус ВЫПОЛНЕНО в СВАРКА)
- [ ] Как **рабочий-грунтовщик**, я не хочу видеть задачу на элемент, пока он не прошёл Покраску (статус ВЫПОЛНЕНО в ПОКРАСКА)
- [ ] Как **рабочий**, я хочу ставить задачу на БЛОК с указанием причины, чтобы мастер мог оперативно реагировать
- [ ] Как **мастер**, я хочу видеть прогресс по Покраске и Грунтовке в своём интерфейсе, чтобы контролировать финальные этапы
- [ ] Как **мастер**, я хочу снимать блоки для рабочих Покраски/Грунтовки так же, как для других специализаций
- [ ] Как **мастер**, я хочу видеть выработку маляров и грунтовщиков в разделе "Выработка", чтобы рассчитывать оплату
- [ ] Как **мастер**, я хочу вносить наряды в вкладки ПОКРАСКА и ГРУНТОВКА вручную в Google Sheets, чтобы распределять работу
- [ ] Как **мастер**, я хочу регистрировать маляров и грунтовщиков в листе СОТРУДНИКИ, чтобы привязать их к специализациям в боте

---

## 6. Acceptance Criteria

Фича считается готовой когда:

- [ ] В каждом активном Google Sheets файле (объекте) созданы вкладки ПОКРАСКА и ГРУНТОВКА со структурой колонок как в СВАРКА
- [ ] В листе СОТРУДНИКИ добавлены разделы для специализаций "Покраска" и "Грунтовка"
- [ ] Синхронизация Sheets → PostgreSQL подхватывает новые вкладки наравне с остальными (каждые 15 минут)
- [ ] Рабочие с этими специализациями идентифицируются в боте по Telegram username и видят только свои задачи
- [ ] Задача на Покраску показывается рабочему только если соответствующий элемент имеет статус ВЫПОЛНЕНО в вкладке СВАРКА
- [ ] Задача на Грунтовку показывается рабочему только если соответствующий элемент имеет статус ВЫПОЛНЕНО в вкладке ПОКРАСКА
- [ ] Рабочий может отметить задачу как ВЫПОЛНЕНО — статус записывается в БД и обратно в Google Sheets
- [ ] Рабочий может поставить задачу на БЛОК с причиной — мастер получает уведомление
- [ ] Мастер может снять БЛОК для Покраски/Грунтовки — рабочий получает уведомление
- [ ] Выработка маляров и грунтовщиков отображается в экране мастера "Выработка"

---

## 7. Scope

### В скоупе (MVP):

- Добавление ПОКРАСКА и ГРУНТОВКА в конфигурацию специализаций (`WORK_SHEETS`)
- Создание вкладок во всех активных файлах Google Sheets с колонками как в СВАРКА
- Добавление разделов Покраска/Грунтовка в лист СОТРУДНИКИ всех объектов
- Подключение к существующей синхронизации Sheets → PostgreSQL
- Настройка зависимостей через существующий механизм (лист ЗАВИСИМОСТИ): СВАРКА → ПОКРАСКА, ПОКРАСКА → ГРУНТОВКА
- Регистрация рабочих (сотрудников цеха) в боте по этим специализациям
- Стандартный флоу бота: список задач, карточка задачи, ВЫПОЛНЕНО, БЛОК, чертёж

### Вне скоупа (later):

- Автоматическое копирование строк из СБОРКИ/СВАРКИ в ПОКРАСКУ при статусе ВЫПОЛНЕНО
- Учёт расхода краски, грунта, типа покрытия
- Отдельная аналитика по финишным этапам
- Загрузка нарядов Покраски/Грунтовки через КМД (Блок 5 в roadmap)

## 8. Риски

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Существующие файлы объектов имеют разную структуру вкладок | Med | Med | До разработки проверить 2–3 реальных файла, выбрать эталон |
| Рабочие не зарегистрированы в системе — бот не выдаст им задачи | Med | Med | Онбординг (Блок 7 roadmap) выполняется параллельно с разработкой |
| Зависимость ПОКРАСКА → ГРУНТОВКА создаёт простои если маляр занят | Low | Med | Блокировка настраивается в листе ЗАВИСИМОСТИ — мастер контролирует |
| Мастер забывает заполнять новые вкладки — рабочие не получают задач | Low | High | Включить в инструкцию мастера (docs/инструкция_мастер.pdf) |

## 9. Зависимости

- Доступ к активным Google Sheets файлам для создания вкладок и обновления листа СОТРУДНИКИ
- Существующий механизм ЗАВИСИМОСТИ (Блок 3) — уже реализован, переиспользуется
- Telegram-аккаунты рабочих (маляров, грунтовщиков) для регистрации в системе
- Инструкция мастера требует обновления — добавить описание новых вкладок
